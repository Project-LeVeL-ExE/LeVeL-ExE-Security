# Security Policy

LeVeL-ExE is a security-oriented project (DNS blocklists and related artifacts). We take reports seriously and prefer **responsible disclosure**.

## What to report here vs. Issues

**Use GitHub Issues** for:
- False positives (legitimate domains blocked)
- False negatives (malicious domains missing)
- List quality, categorization, or compatibility/breakage reports

**Use the private channel below** for:
- Repository compromise indicators (malicious commits, tampering, suspicious releases)
- Supply-chain / CI integrity issues (Actions, secrets, tokens)
- Any issue that could materially endanger users if discussed publicly first

## Private reporting

Email: **project@level-exe.com**

Please include:
- A clear description of the issue and impact
- Reproduction steps (if applicable)
- Relevant logs, hashes, URLs, commits, or timestamps
- Suggested remediation (if you have one)

## Response targets (best effort)

- Acknowledgement: within **72 hours**
- Initial triage: within **7 days**
- Fix / mitigation timeline depends on severity and complexity

## Public disclosure

Please avoid public disclosure until we confirm and ship a mitigation, unless coordinated with us.
